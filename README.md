# RideFlow — Complete Uber-Style Ride Booking Platform

**RideFlow** is a modern, full-stack ride-hailing and fleet operations platform inspired by Uber. It features an integrated Passenger App, Driver App, and Operations Admin Dashboard with live GPS tracking, atomic driver dispatch, authoritative fare calculation, simulated & Stripe payments, and a 4-digit pickup PIN verification flow.

---

## 🚀 Key Features

### 1. Passenger Application
- **Interactive Map:** Powered by Leaflet with custom road polyline route visualization, live car movement, and landmark autocomplete.
- **Ride Category Options:**
  - **RideFlow Eco:** Affordable, everyday rides (4 seats).
  - **RideFlow Comfort:** Newer vehicles with legroom (4 seats).
  - **RideFlow Black:** Luxury sedans with professional chauffeurs (4 seats).
  - **RideFlow XL:** Spacious SUVs for groups up to 6 passengers.
- **Dynamic Estimates:** Authoritative distance, travel duration (ETA), and price calculated server-side.
- **Trip Security PIN:** 4-digit numeric code generated by the server that the passenger provides to the driver to start the trip.
- **Itemized Receipts & Payments:** Complete fare breakdown (base fare, distance, duration, surge, platform fee) with 1-click test payment and idempotency protection.
- **5-Star Rating & Reviews:** Leave driver compliments and comments.
- **Dispute & Support Resolution:** Report trip issues directly to platform operations.

### 2. Driver Application
- **Driver Console:** Online/offline availability toggle with strict verification status guard (only approved drivers can go online).
- **Urgent Incoming Offer Modal:** 25-second countdown timer, estimated net earnings, pickup distance, and 1-click accept/decline.
- **Turn-by-Turn Lifecycle:**
  1. *Navigating to Pickup* &rarr; "I Have Arrived"
  2. *At Pickup* &rarr; Verified 4-digit PIN entry to start trip
  3. *In Progress* &rarr; Live navigation & route tracking
  4. *Complete Trip* &rarr; Server finalizes fare and credits driver net earnings
- **Earnings Accounting:** Today's payout, gross fares, platform commission (20%), and net earnings history.

### 3. Platform Operations (Admin Dashboard)
- **Analytics & Trends:** Interactive charts (Recharts) for gross booking volume, daily trip volume, platform commission, and online drivers.
- **Driver Verification Queue:** Review pending driver applications (license, vehicle registration) and approve or reject with 1 click.
- **Algorithmic Pricing Rules:** Dynamically adjust base fare, per-km rate, per-minute rate, and surge multipliers per category.
- **Fleet Inspection:** Query all platform rides with status filtering.
- **Security Audit Trail:** Immutable log of all administrative actions.

### 4. Matching & Dispatch Engine
- Dispatches ride offers to eligible drivers within a configurable radius (`DISPATCH_RADIUS_KM`).
- **Atomic Acceptance:** Concurrency-safe atomic database locking ensures that only one driver can win a ride offer, preventing double assignments or conflicting trips.
- Automatic offer expiration and fallback to subsequent drivers.

## 📦 Installation & Setup

### Prerequisites
- Node.js (v18+)
- MongoDB (Running locally on `mongodb://127.0.0.1:27017` or configured via `MONGODB_URI`)

### 1. Clone & Install Dependencies
```bash
# Install root dependencies
npm install

# Install server dependencies
cd server && npm install

# Install client dependencies
cd ../client && npm install
```

### 2. Configure Environment
```bash
# Server configuration
cp server/.env.example server/.env
```

Default `.env` configuration:
```ini
PORT=5001
NODE_ENV=development
CLIENT_URL=http://localhost:5173
MONGODB_URI=mongodb://127.0.0.1:27017/rideflow
JWT_SECRET=rideflow_super_secret_jwt_key_2026
MAP_PROVIDER=simulation
PAYMENT_MODE=development
DISPATCH_RADIUS_KM=15
OFFER_TIMEOUT_SEC=25
```

### 3. Seed Database with Demo Accounts
```bash
npm run seed
```

This populates the database with realistic demo accounts:

Run both backend and frontend concurrently:

## 📱 Multi-Role Demo Switcher

RideFlow includes a **Demo Quick Switcher** banner at the top of the app in development mode. You can open two different browser tabs (e.g. Tab 1 as Passenger Alice, Tab 2 as Driver Carlos):
1. In Tab 1, book a ride from Market St to Pier 39.
2. In Tab 2, Carlos will immediately receive the incoming ride offer modal with the countdown.
3. Accept the ride in Tab 2 &rarr; Tab 1 will show Carlos en route along with the 4-digit PIN!
4. Carlos clicks "I Have Arrived", inputs the PIN, starts the trip, and completes it.
5. Alice completes the payment and leaves a 5-star rating!
